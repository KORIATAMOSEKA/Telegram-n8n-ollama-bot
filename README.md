# Local Telegram AI Chatbot with n8n & Ollama
[Telegram Bot Demo](Demo.png)
An automated, privacy-focused Telegram AI chatbot built using **n8n** and a locally hosted **Ollama** model (llama3.2). This setup provides a fast, zero-cloud-dependency conversational workflow with no API rate limits or recurring costs. ## 🌟 Key Features - **Local AI Execution:** Powered by Ollama (llama3.2) running directly on host hardware. - **n8n Workflow Automation:** Orchestrates incoming message handling, AI agent memory, and outgoing Telegram responses. - **Message Chunking & Safeguards:** Formatted outputs tailored to fit Telegram's strict 4,096-character limit. - **Persistent Conversational Context:** Utilizes n8n AI agent architecture with window buffer memory to maintain multi-turn chat history. ## 📐 Architecture Overview 1. **Telegram API / HTTP Request:** Event-driven capture of incoming user messages from Telegram. 2. **n8n AI Agent:** Manages conversational state, session keys, and prompt assembly. 3. **Ollama Chat Model:** Local LLM inference engine executing llama3.2 without external network dependency. 4. **Send Text Message Node:** Routes generated response strings back to the original Telegram chat ID. ## 🚀 Getting Started ### Prerequisites - [n8n](https://n8n.io/) installed locally or via Docker - [Ollama](https://ollama.com/) running locally with the model pulled:

bash
ollama pull llama3.2
